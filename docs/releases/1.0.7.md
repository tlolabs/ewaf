# EWAF 1.0.7

This patch retains the established date, search, preview, confirmation and safe folder-creation behavior while reducing avoidable work. Rust rejects normalized search shapes that cannot occur in ASCII folder names, streams complete date names into ABI JSON without a temporary string collection, and serves metadata-only macOS plan initialization. The shared Qt presentation retains preview rows during progress updates.

Release microbenchmarks on Apple Silicon measured maximum-range C ABI request/free latency from 10.24 to 4.19 ms and allocations from 521,747 to 23. These are workload-specific results; valid late-date searches still scan the range, and application-wide startup/idle gains are unverified. Native Windows/Linux and Intel runtime performance were not measured.

Local macOS distributable packaging requires Developer ID signing, Apple Accepted notarization, stapling and final-archive Gatekeeper verification. Development packages remain explicitly unnotarized. This release does not enroll an authenticated updater or change its trust checks. The Sunday-only CI smoke policy remains unchanged.

Version 1.0.7 is synchronized across Cargo, CMake, the application lockfile entries and the generated Xcode project. Validation passed: locked Rust formatting/clippy and 48 workspace tests, 43 release Swift tests, 23 shared Qt offscreen scenarios, 42 release-tool tests, 14 notarization mock tests, version/icon checks and dependency-inventory checks. The separately invoked Sparkle signing-tool interoperability test also passed.

The universal macOS ZIP contains Apple Silicon and Intel slices, uses Developer ID signing and was accepted by Apple (submission `4cf20195-c286-4c3d-b05c-8693f61c97c8`). The app was stapled and validated; both the staged app and the app extracted from the final ZIP passed Gatekeeper as Notarized Developer ID. The notarized app passed a host Apple Silicon launch smoke test.

Artifact: `EWAF-1.0.7-macos-universal.zip`. SHA-256: `fb2f8a2ae528f20b763272f64a10fee98109d6a91d7b7eacf7018b7fba791605`.

An independent Antigravity review selected `gemini-3.8-flash-high` (High reasoning), returned complete coverage with no findings, and was assessed by Codex. Model attribution is the CLI selection; independent backend identity was not exposed. Gemini inspected source and runner-executed checks, including offline signing mocks; the real Apple result is separate artifact evidence obtained by Codex.

Native Windows/Linux packages, Intel runtime execution and Xcode UI automation remain unverified; no skipped platform is counted as passed.
