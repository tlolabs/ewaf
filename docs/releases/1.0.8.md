# EWAF 1.0.8

This version fixes destination permission-error classification, prevents Qt smoke tests from overwriting normal preferences, and speeds up exact-date preview searches without changing date/search contracts or the ABI.

Local macOS ARM64 verification includes Rust behavior/ABI/updater tests, all 43 Swift tests, 24 shared Qt scenarios including real-application smoke subprocesses, formatting, Clippy, version alignment, icon validation, 42 release helper tests and 14 notarization workflow tests. The explicit development package passed package validation and startup. Xcode UI testing failed before test execution because automation mode could not initialize; package validation does not establish interactive accessibility acceptance.

Repeated maximum-range microbenchmarks measured 7.1–9.5× faster stored-plan exact-date queries and 1.19–1.29× faster bounded request previews on this Mac. See [performance evidence](../PERFORMANCE.md). No Windows/Linux performance or native package acceptance is inferred from shared source.

The requested Gemini/Codex/Copilot/Codex sequence preserves each review’s actual snapshot and model attribution. Gemini’s configured `gemini-3.8-flash-high` invocation failed because inherited headless permissions denied source reads. Copilot returned partial observations with no findings but omitted its required fresh review token, so the runner rejected the report. Neither invocation is an accepted audit. Codex assessed the observations and corrected a Linux portability issue in the new permission regression test. Details are recorded in the [audit report](../audits/2026-11-16-two-loop.md).

Distribution remains separate from implementation. `SIGNING_IDENTITY` and `NOTARY_PROFILE` were absent, so the distributable macOS path stopped at its prerequisite check. The local `development-unnotarized` ZIP is for development/testing and is not a release asset or authenticated update. Native Windows/Linux packages were not built in this local pass. Only qualified platform packages may be uploaded; missing platforms remain explicit. Existing Sunday-only CI and authenticated-update verification are unchanged.
