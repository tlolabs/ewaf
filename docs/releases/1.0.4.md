# EWAF 1.0.4

EWAF gains a shared folder/calendar icon on macOS, Windows and Linux, highlighting Tuesday and Thursday. macOS includes native light, dark and tinted Icon Composer appearances plus a compatibility icon for macOS 14 and later. Local macOS builds refresh their registered icon after rebuilding.

Native projects and tests are organized by platform. Legacy Python-derived fixture data has been removed; native date, persistence, boundary and filesystem regression coverage remains. Folder naming, date selection, creation, cancellation, recovery and saved preference formats are unchanged.

Packages support macOS 14+ (Apple Silicon and Intel), Windows 10 1809+ (x64 and ARM64), and Ubuntu 24.04 (amd64 and arm64). Each platform package must pass the release commit's complete native validation matrix before publication.

The owner requested publication with the remaining manual screen-reader, display/scaling, minimum-OS and interactive picker acceptance checks documented in docs/PARITY.md. Those checks are not claimed as completed. Windows packages are unsigned; Linux downloads are standalone Debian packages with SHA-256 checksums.
