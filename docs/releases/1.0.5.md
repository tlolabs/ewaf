# EWAF 1.0.5 release candidate

## Changes

- Windows and Linux now use the shared Qt 6 Widgets presentation in place of the retired Avalonia UI. Production macOS retains its native SwiftUI/AppKit application. The internal macOS ARM64 Qt build remains a separate reference and is excluded from production packages.
- Keyboard focus, accessible control descriptions, progress wording, preview selection, and System/Light/Dark appearance received cross-platform fixes and regression coverage.
- The shared Rust core remains authoritative for dates, folder naming, planning, creation, conflicts, and recovery. Existing folders and their contents remain untouched on repeat creation.
- Date formatting, search previews, and macOS date bridging use fewer allocations without changing folder names or date rules.

## Supported packages and verification

The [seven-target native CI matrix](https://github.com/tlolabs/ewaf/actions/runs/37709304541) passed on commit `8e19172800f121bcb032117e47efea9eb93e58bd`: production macOS ARM64/x64, Windows ARM64/x64, Linux ARM64/x64, and the internal Qt ARM64 reference. It includes native macOS UI tests, Windows packaged UI Automation and installer checks, Linux installed package and window checks, and shared Rust/Qt regression suites. The internal reference is not a release asset.

Production targets are macOS 14 or later, Windows 10 version 1809 or later, and Ubuntu 24.04 as the Linux baseline. Minimum-OS, screen-reader, high-contrast, and mixed-DPI manual acceptance remains open; the CI run does not establish those results. See [platform parity](../PARITY.md).

## Release hold

This candidate is **not yet approved for a stable tagged release**. Production update trust is not enrolled, the Windows distribution approval gate is unset, and the required signing/notarization environment is not configured. The stable tag workflow must pass those gates and validate signed artifacts from one commit before a draft release can be published. See [release policy](../RELEASING.md) and [update qualification](../UPDATING.md). The earlier `v1.0.4` tag refers to older code.
