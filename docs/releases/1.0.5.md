# EWAF 1.0.5

This version reduces allocations in date formatting, search previews and macOS date bridging. The shared Rust core remains authoritative for date planning and folder creation. No folder names, date rules, preference keys or creation behavior change.

The macOS download is a ZIP containing `EWAF.app` for macOS 14 and later on Apple Silicon and Intel. Release artifacts must pass their platform validation before publication. Windows and Linux continue to use their native interfaces and the shared Rust core; their native validation for this commit is pending.

The existing `v1.0.4` tag refers to older code. The remaining manual acceptance checks are listed in [the parity matrix](../PARITY.md). The Windows redistribution review and stable release hold remain in [the release policy](../RELEASING.md).
