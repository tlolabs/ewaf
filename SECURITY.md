# Security policy

## Supported versions

Security fixes target the latest stable EWAF release and current `main`. Older releases are not maintained. See [GitHub Releases](https://github.com/tlolabs/ewaf/releases) for the latest version.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/tlolabs/ewaf/security/advisories/new) when available. Do not publish an exploitable issue in GitHub Issues. Public security email: **TBD**. If private reporting is unavailable, contact Thomas Lothian privately through the repository owner profile and ask for a secure channel without including exploit details in public text.

Please include affected version, impact, reproduction steps and a safe proof of concept. The maintainer will acknowledge, assess, coordinate a fix and credit reporters who wish to be named. Avoid accessing other users' data or disrupting services while testing. Security releases are published through GitHub Releases with any supported platform limitations clearly stated.
