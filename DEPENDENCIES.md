# Dependencies

Machine-readable manifests and lockfiles are authoritative. Cargo workspace version is the single application version. `script/check_versions.py` checks native metadata copies.

| Dependency | Purpose | Version control |
| --- | --- | --- |
| Rust toolchain | Core/ABI compiler, formatting, linting | `rust-toolchain.toml` (1.98.1); crate MSRV declared in workspace |
| Chrono | Proleptic Gregorian date correctness | Workspace Cargo.toml + Cargo.lock; no timezone/runtime clock features |
| cap-std / cap-primitives | Open-directory-relative portable filesystem operations and metadata | Cargo.toml + Cargo.lock |
| serde / serde_json | Typed ABI requests and explicit result serialization | Cargo.toml + Cargo.lock |
| unicode-normalization | Full-width search compatibility | Cargo.toml + Cargo.lock |
| tempfile | Isolated Rust filesystem tests only | Cargo.toml + Cargo.lock |
| Swift 6 / SwiftUI / Foundation | macOS UI, settings, timezone adapters and tests | Package.swift and selected Xcode toolchain; no third-party Swift package |
| .NET 8 | Windows native application and C# adapter | Windows project manifests / Actions setup-dotnet |
| Microsoft.WindowsAppSDK | WinUI 3 desktop controls/runtime | EWAF.csproj, exact package version 2.4.0; packages.lock.json generated by native restore and must be committed after first successful restore |
| GTK 4.10+ / libadwaita 1.4+ / json-glib | Linux native UI, settings, async tasks and ABI JSON adapter | Ubuntu 24.04 distribution packages in CI; pkg-config build requirements |
| Python 3 | Build/version/packaging tools and retained reference tests; never a native runtime dependency | CI Python matrix; build scripts use standard library |
| ttkbootstrap | Retained Python UI only | Root and legacy-python requirements.txt; not linked or shipped in native apps |

Rust third-party licenses are available in crate package metadata/source distributions (Chrono MIT/Apache-2.0, cap-std Apache-2.0 with LLVM exception/Apache-2.0/MIT options, serde MIT/Apache-2.0, unicode-normalization MIT/Apache-2.0). Microsoft and GNOME components retain their upstream licenses. No repository license is invented by this migration. Distribution must preserve applicable notices; GTK/libadwaita are dynamically supplied by the Linux distribution. Windows publish output includes its self-contained runtime assets.

Dependabot monitors Cargo, NuGet, GitHub Actions and retained Python requirements. Review upgrades on all platforms, regenerate locks, run full CI and assess minimum-OS implications. Do not copy a local build directory's libraries into an unrelated architecture package. Never commit signing credentials.
